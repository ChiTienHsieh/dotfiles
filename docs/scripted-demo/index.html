scripted-demo：會自己演的操作示範

每個示範都是一個 HTML 檔：假游標（手機版是手指）照劇本自己點，正在講的地方會打亮，下面有旁白，可以上一步、下一步、調速度，也可以按「自己點點看」直接操作。

點開任一個，按「▶ 播放」。

自己做一個

skill 本體在 GitHub 的 skills/shared/scripted-demo。把整個資料夾放進 ~/.claude/skills/，開 Claude Code 說「幫我做一個會自己演的 demo，示範 xxx 流程，給 yyy 看」。示範手機畫面時，跟 Claude 說「這是手機畫面」。

只下載這個資料夾：

git clone --depth 1 --filter=blob:none --sparse https://github.com/ChiTienHsieh/dotfiles.git && git -C dotfiles sparse-checkout set skills/shared/scripted-demo
