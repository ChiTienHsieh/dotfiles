# scripted-demo：讓 Claude 做會自己演的操作示範

## 你一定看過這種東西

剛裝好一款手遊，畫面突然變暗，只剩一顆按鈕是亮的。一隻手指在上面一直點，旁邊跳出一行字：「點這裡，召喚你的第一隻角色」。你照著點，它再帶你去下一顆按鈕。

這個 skill 就是讓 Claude 幫你做這種東西，只是對象換成任何你想教別人的操作流程。

## 先打開範例看看

用瀏覽器打開 [`assets/example-bubble-tea.html`](assets/example-bubble-tea.html)，按底下的「▶ 播放」。

它示範一台手搖飲自助點餐機：點一杯半糖少冰的珍奶、半路改主意換成微糖、最後結帳拿號碼牌。你會看到：

- 看起來像一台影片播放器：深色外框包住點餐機，底下是控制列
- 一個游標自己移動、自己點，正在講的地方會亮起來，其他地方變暗
- 控制列上一行字說明現在在做什麼
- 每一段開始前有一張卡片說這段要示範什麼，結束後有一張卡片整理重點
- 可以上一步、下一步、暫停、調快調慢、點進度條跳到任何一步，鍵盤的 → ← 空白鍵也能用
- 按「自己點點看」，可以直接操作點餐機
- 按「☾ 深色」切成深色模式：點餐機變暗，外框和控制列換成米白，一樣分得出哪裡是播放器

## 什麼時候用得上

| 場合 | 怎麼用 |
|---|---|
| 寫操作文件 | 文字說明旁邊附一個示範檔，看不懂的人打開來看一次就懂 |
| Teams 遠端教學 | 分享螢幕，一步一步按「下一步」，邊講邊停，不怕手忙腳亂點錯 |
| 開會討論設計方案 | 每個方案做成一段，演一遍給大家看，最後的卡片列出各自的好處與要注意的地方 |
| 推廣新功能 | 讓第一次接觸的人，不用自己摸索就看到完整流程 |
| 新人教育訓練 | 把常問的操作做成幾段示範，新人自己看 |

它是「演出來的」：畫面是照真的系統畫的，但不會真的去操作那個系統，所以不會動到任何真實資料，也可以示範還不存在的新設計。

## 怎麼請 Claude 做

把這個資料夾放進 Claude Code 的 skills 目錄（例如 `.claude/skills/scripted-demo/`）後開 Claude Code，直接描述你想示範什麼就好，例如：

```text
幫我做一個能上一步、下一步的導覽，教新人怎麼在 GitLab 開 issue，給 Teams 遠端教學用。
```

```text
我們有兩個登入頁的設計方案，做成會自己演的示範，開會時一起看，最後幫我列出各自的好處和要注意的地方。
```

```text
操作文件想附一段會自己點的示範：怎麼在 Excel 做樞紐分析。觀眾是沒碰過 Excel 的行政同仁。
```

講得越清楚，結果越好：

- **示範什麼流程**：從哪裡開始、到哪裡結束
- **給誰看**：一般同事、主管、還是新人；Claude 會依觀眾調整用詞
- **分幾段**：例如「正常流程」「填錯怎麼改」「完成之後」
- **長什麼樣**：有現成系統就說是哪個系統，Claude 會照它的樣子畫

## 拿到什麼

一個 HTML 檔，用瀏覽器打開就能看，不用安裝任何東西，傳給別人也只要傳這一個檔。另外會有一個檔名帶 `.src` 的檔案，之後要改內容時用；改完請 Claude 重新產出就好。

## 維護

- 播放器（游標、亮框、控制列那些東西）只有一份：[`assets/player.js`](assets/player.js)。要修 bug 或加功能，改這一份就好，以後產出的示範都會帶到。
- 給 Claude 看的說明在 [`SKILL.md`](SKILL.md)。
