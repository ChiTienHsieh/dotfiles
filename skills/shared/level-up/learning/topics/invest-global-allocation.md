## Fable 的決策（Opus 帶 user 逐關重走）

### D1：39w 容器 → **主推 VWRA，富邦複委託買**
- VWRA = Vanguard FTSE All-World UCITS ETF（累積型，愛爾蘭註冊，LSE 掛牌）。
- 理由：美股股息預扣 15%（美掛 VT 是 30%）；愛爾蘭註冊不吃美國遺產稅（非居民美國資產超過約 $60k 就有曝險）；累積型自動複投，零收入年不需要現金流；user 富邦銀行＋富邦證券都有了。
- 備選（嫌麻煩版）：台灣掛牌全球型（台版 VT 009826 / 標普500 00646），用現有台股帳戶最順手；代價是基金層級股息被扣 30% 拿不回。
- 不推：IBKR（這個金額/階段，開海外券商的維運成本＞省下的錢）；eToro 放正式部位（CFD 對手風險）。
- **決策樹**：若查證後富邦複委託買不到 LSE 的 VWRA 或最低手續費太傷 → 退回台版容器，不硬上 IBKR。

### D2：配息 vs 累積 → **選累積型**
- 零收入年聽起來該要現金流，其實相反：配息在台灣是海外所得、還要手動再投入付手續費；「賣一點去旅遊」的彈性靠賣股達成，不靠配息。讓他自己走到這結論。

### D3：真避險 = 承認三重集中
- 決策確認目標：user 能自己說出「薪水＋房＋0050 是同一注」，並確認 39w 海外倉位就是避險本體，不是加菜。

### D4：bitcoin → **現貨、閒錢 1–2% 上限、心理直接歸零計、絕不開槓桿/CFD**
- 類比：衝 10% 卷軸 —— 拿一張卷的預算，不是拿整套裝備賭。
- 買法（台灣合規交易所 vs 美股 ETF 化商品）留給 user 拍板 —— 真決策點，別替他選。

### D5（已拍板，不用重教）：eToro $300 給 AI agent 玩 → 核可
- user 的範式：隔離帳戶＋金額有上限＝爆炸半徑受控；紅線只有一條 = 別把主帳戶/全部身家的鑰匙交出去；若小錢翻大額，盡快出金落袋。
