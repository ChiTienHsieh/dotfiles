# 裝修優先序與溝通

## Learner Goal
- 搞懂中和老家裝修優先順序，並產出多則可傳給晨清的 LINE 回覆（多則分開回覆她的原文、像 cite 原文一樣精準）。
- 核心生活目標：讓老婆住起來舒服。老婆怕蟲、不喜歡現在浴室，第一優先偏向「浴室做到老婆滿意」與「防蟲」。

## Status
- learning，confidence medium。Analogy：Vainglory shotcaller（優先序、資源取捨、first objective vs 後期裝備）。

## 已收斂的優先序與預算（operational，會議/LINE 決策依據）
- **浴室（一期核心）**：標準全拆翻新（入門級距 15–30 萬），重點=乾淨舒服、防水排水、減少馬桶區濕，不硬搬洗手台。真正目標是洗完澡馬桶區盡量不濕、排水快、易乾，不追飯店級完整玻璃淋浴間；小浴室可接受半屏/短拉門折衷，但排水、坡度、抽風要一起做好。老婆不喜歡原因：舊、髒、磁磚醜、怕蟲怕潮怕排水孔、沒乾濕分離濕答答。
- **防蟲（一期核心）**：先辨認蟲種與入口。蟑螂是硬性必防（廚房水槽/櫥櫃下、浴室排水孔、管線孔、門窗縫）；使用者個人討厭雨天聚集的飛白蟻/大水蟻（非結構白蟻）。一期優先封孔、排水孔防蟲、廚房水槽下檢查，而非先全屋高級氣密窗。
- **門窗分期**：一期先處理臥室、廚房、浴室相關開口，客廳/陽台視預算分期。
- **通風**：全熱交換器先列現場評估/研究，不當一期必做。第一層浴室排濕/排味/乾燥必做；第二層臥室可控新鮮空氣（好紗窗短暫開窗或單房間換氣設備）。使用者因怕外面灰塵少開窗、擔心悶。
- **冷氣/睡眠**：噪音來自冷氣本身與外部環境兩者。臥室一期舒適包可評估氣密窗+紗窗+遮光+分離式冷氣+可控通風；使用者主要想解睡眠噪音（老婆沒差）。
- **陽台**：低成本保護洗衣機，完整封陽台暫不列主線。
- **預算**：可能提高到約 50 萬，仍以現場評估+必要性加價，非全買。**若爆預算，優先砍全熱交換器、完整封陽台、客廳大面門窗、全屋冷氣等非核心項，不砍浴室、防蟑螂、臥室睡眠核心。**

## 已掌握 / 誤解修正
- 浴室最大陷阱：未現場看管線就先承諾小修 → 應先理解現實樣貌再跟設計師討論。
- 乾濕分離的真目標是「馬桶區不濕、易乾」而非硬追完整玻璃淋浴間；玻璃不能忽略水流和濕氣。

## Known Gaps
- 尚未拆解浴室「大拆重做 vs 小修明管 vs 保留配置」的接受度；使用者對「明管」缺乏視覺/工程想像。
- 尚未釐清蟲種、樓層、主要入侵路徑。
- 尚未把「少開窗/怕灰塵」的通風需求轉成全熱交換器或替代方案的決策條件。

## Teaching Notes
- Vainglory shotcaller 類比：priority、resource tradeoff、first objective vs late-game item。可延續刺客/gank 防線比喻。
- 本 phase 除非被要求，不 draft LINE 訊息；聚焦收集脈絡、chunk 優先序、建立裝修取捨的 mental model。
- 若之後 draft LINE：短、非廢話（先前 draft 太長）。
- 決策綁回老婆舒適，不綁抽象裝修完整度。

## Next Suggested Levels
- 浴室決策樹與回覆段落。
- 防蟲與門窗決策樹。
- 冷氣與全熱交換器取捨，尤其少開窗與灰塵焦慮。
