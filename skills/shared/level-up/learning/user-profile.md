# 教學偏好

只保留會影響下一堂課的已確認偏好；知識狀態見 [索引](INDEX.md)。

- 用自然台灣口語，把一句話講完；短回合、一回合一件事，避免一次倒完整份報告。
- 熟悉、可拿來當譬喻的世界：Vainglory（手遊 MOBA，自報 top 0.1%；協調、時機、取捨、每場重置的 power curve）、《葬送的芙莉蓮》（2026-09-08 起；角色動機、長期累積、留給未來的決定、偏航與修正；芙莉蓮＝本人、費倫＝agent、欣梅爾＝留給未來的原則，一次少用幾個角色）、舊楓之谷（只有 Big Bang 改版前那版）。同一概念只用一個世界，全課一致。
- 不熟、不要拿來當譬喻：新版楓之谷、Roguelike、多重保險庫故事。
- Vainglory 專有名詞不憑印象講：機制層可直接用，英雄、技能、秒數、道具名要停在機制層、用使用者給的例子，或先確認。
- 2026-09-06：使用者可要求 `/chill` 外殼（同事群、PTT 說故事口吻）疊在概念類比上，實測有效；Level 0 可列為選項，概念類比世界仍只用一個。
- 類比要幫助理解因果，幽默可以提高投入；若故事增加負擔，直接講技術更好。
- 深度與呈現方式依當次選擇，不把某堂課的設定當成永久預設。
- 2026-07-13：一次只問一題，先給簡短方向，再逐步展開。
- 2026-08-25：精簡不等於電報文；每回合仍須把概念與理由說清楚。
- 2026-09-03：終端機避免圈圈數字，使用一般數字；說「判斷標準」。
- 2026-09-06：「拍板」是廢詞，一律寫「決定」；同類廢詞：安心話、過堂、判準、合帳。
- 2026-09-05：講解未讀過的程式碼時，型別與欄位名都是生詞；先建詞彙，再談決策，不能用大量識別字當解釋。
